# SISTEMA DE TICKETS PARA LA ATENCIÓN EN EL ÁREA DE SOPORTE TÉCNICO

Para brindar el servicio a nuestros clientes de manera más ordenada y adecuada, se desarrolla este sistema con el fin atender a sus necesidades.
## 🚀 Características principales
* Muestra General de las asistencias técnicas a los clientes.
* Registro de las asistencias técnicas a los clientes.
* Modificación de las asistencias técnicas.
* Eliminación de las asistencias técnicas.
* Generación de código de tickets para la atención.
* Impresión del tickets para la atención.

## ⚙️ Instalación
Pasos detallados para configurar el entorno de desarrollo local:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com](https://github.com/christianraul/soporte-tecnico-ticket)
   ```
2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd tu-proyecto
   ```
3. **Instalar dependencias:**
   ```bash
   npm install  # o pip install -r requirements.txt
   ```
4. **Configurar variables de entorno:**
   Copia el archivo `.env.example` a `.env` y ajusta tus credenciales.
